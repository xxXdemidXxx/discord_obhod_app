ByPass 0.5.9 — КАК ЗАПУСТИТЬ

1. Скачайте ByPass-win-x64.zip:
   https://github.com/xxXdemidXxx/discord_obhod_app/releases/latest/download/ByPass-win-x64.zip
2. Нажмите на ZIP правой кнопкой мыши → «Извлечь всё» → «Извлечь».
3. Откройте распакованную папку ByPass и запустите ByPass.exe.
4. Нажмите «Подобрать автоматически». В вопросе Windows нажмите «Да».
5. Дождитесь результата. Откройте YouTube или Discord и проверьте работу.

Нужны Windows 10/11, 64 бит, и .NET Framework 4.8.
Не переносите один EXE: сохраняйте всю папку ByPass вместе с data.
Git, команды и сборка программы не нужны.

КАК ЭТО РАБОТАЕТ
Программа пробует разные способы передачи сетевых пакетов, чтобы обойти
поддерживаемые фильтры провайдера. IP-адрес и страна остаются прежними.
Результат зависит от сети. Видео YouTube и голос Discord проверьте сами.
Для Discord проверяются приложение, Gateway и обновления с пробой CDN.
Успех этих проб не подтверждает запуск установленного клиента.
Для проверки обхода выключите VPN и повторите подбор.

ЕСЛИ НЕ ЗАРАБОТАЛО
- Выберите «Полный» режим и повторите автоматический подбор.
- При ошибке DNS нажмите «Диагностика DNS».
- Если запущен другой zapret, сначала выключите его.
- Если обход не удалось включить, прочитайте подсказку в окне.
  Технические подробности доступны по кнопке «Журнал».
- Если доступен только GitHub и написано «обход выключен», сначала включите
  обход или запустите автоподбор. Проверка сервисов сама его не включает.
- Настройки игр и «Дополнительно» для обычного запуска менять не нужно.

КАК ВЫКЛЮЧИТЬ
Кнопка «Выключить» останавливает обход.
Крестик скрывает окно, программа продолжает работать.
Для полного выхода: правой кнопкой на значок рядом с часами → «Выход».
Если значка не видно, нажмите стрелку ^ рядом с часами.
Размер окна можно менять, потянув за край или угол.
Кнопка □ разворачивает окно, повторное нажатие возвращает прежний размер.
Отметка подписи автора находится во вкладке «Помощь».

ОБНОВЛЕНИЯ
Надпись «Доступна новая версия оболочки» относится к самому ByPass.
Надпись «Доступна новая версия ядра» относится к компонентам обхода.
Нажмите «Обновить» и выберите «Да» или «Нет» в вопросе о подтверждении.
По умолчанию скачивание и установка требуют этого подтверждения.
Можно включить «Скачивать и устанавливать автоматически» во вкладке
«Обновления» отдельно для оболочки и ядра. Тогда при запуске новая версия
будет скачиваться и устанавливаться без вопроса. Приложение может
перезапуститься, а подключение кратковременно прерваться и восстановиться.
Автообновления можно выключить теми же переключателями.
Для обновления ядра сначала выключите обход, после установки включите снова.
При обновлении оболочки программа перезапустится и сохранит настройки.

КАК ПРИСЛАТЬ ЛОГ
Откройте «Журнал» → «Сохранить лог» → выберите папку → «Сохранить».
Отправьте полученный TXT-файл разработчику вместе с описанием проблемы.
Файл содержит версии и сообщения приложения. Проверьте его перед отправкой:
в сообщениях могут встречаться адреса проверенных вами сайтов.

Подробная помощь:
https://github.com/xxXdemidXxx/discord_obhod_app/blob/main/USAGE.md
Сообщить о проблеме:
https://github.com/xxXdemidXxx/discord_obhod_app/issues

БЕЗОПАСНОСТЬ
Обновления проверяются по подписи, а файлы ядра — перед каждым запуском.
Запрос Windows относится к отдельному компоненту запуска ядра.
Если проверка файлов не пройдена, распакуйте новый полный ZIP в новую папку.
При сообщении антивируса об угрозе не отключайте защиту и не добавляйте исключения.
Сохраните название обнаружения и сообщите о проблеме по ссылке выше.
Сертификата проверенного издателя пока нет: предупреждение SmartScreen возможно.

ПОСЛЕ СЕТЕВЫХ ПРОБ
Проверьте запуск Discord и YouTube. «Работает» сохраняет подтверждённый вами вариант; «Не работает» продолжает подбор, пропуская отклонённые варианты. При ошибке драйвера подбор остановится: перезагрузите компьютер, повторите запуск и сохраните новый журнал, если ошибка останется.

СТАРАЯ СЛУЖБА WIN DIVERT
Если в Windows осталась остановленная служба WinDivert с отсутствующим файлом старого zapret, программа очистит только эту устаревшую регистрацию перед запуском. При сообщении об ожидании удаления службы перезагрузите компьютер и повторите запуск.

АВТОЗАПУСК WINDOWS
Откройте «Настройки» и включите «Запускать при старте Windows».
Подтвердите запрос Windows. Устанавливается отдельная служба ByPass.
При следующем старте Windows обход включится до входа в систему.
После входа ByPass появится только в трее; окно само не открывается.
Двойной щелчок по значку открывает окно. «Выход» при включённой галочке
оставляет службу работающей. «Выключить» останавливает её до следующей
загрузки Windows. Снятие галочки удаляет службу и запуск значка.
Держите программу в постоянной распакованной папке. Перед переносом
отключите автозапуск в прежней папке, после переноса включите снова.
Проверьте вручную перезагрузку, смену стратегии и снятие галочки.
YOUTUBE БЕЗ ИЗМЕНЕНИЯ DNS WINDOWS
Оставьте обход включённым. Нажмите «Диагностика DNS» →
«Открыть YouTube в отдельном окне». Нужен установленный Edge или Chrome.
Для этого окна создаётся отдельный профиль и используется DNS через HTTPS.
DNS Windows, системный прокси, роутер и основной браузер не изменяются.
ByPass должен оставаться работающим. После выхода/обновления ByPass
откройте отдельное окно заново этой кнопкой. Проверьте воспроизведение ролика.
Красная DNS-проверка в ByPass может сохраняться: она использует DNS Windows.

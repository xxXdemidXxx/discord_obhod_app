ОБХОД 0.3.0 — ТЕСТИРОВАНИЕ С ДРУЗЬЯМИ

Что отправить
1. Отправьте Obhod-0.3.0-win-x64.zip из GitHub Releases:
   https://github.com/xxXdemidXxx/discord_obhod_app/releases/latest
2. Другу нужно распаковать всю папку Obhod в постоянное место и открыть Obhod.exe.
   Не отправляйте один EXE: нужны папка data, ядро и библиотеки.
   Требуется Windows 10/11 x64, .NET Framework 4.8.

Как пользоваться
1. Если уже работает старый zapret, завершите его через исходный service.bat.
   Старую оболочку закройте через «Выход» в меню значка у часов.
2. Откройте Obhod.exe. Для первого теста нажмите «Автоподбор всех стратегий».
   Подтвердите запрос администратора Windows. Консоль winws не откроется.
3. На одной странице видны стратегия, результаты пяти сервисов и таблица всех вариантов.
   Автоподбор занимает несколько минут и проверяет победителя повторно.
4. Чтобы вручную попробовать вариант, выберите его → «Применить и проверить».
   Выключать предыдущий вариант вручную и менять вкладки не нужно.
5. Проверьте YouTube-видео и голосовой канал Discord отдельно: HTTPS 5/5 не гарантирует их работу.
6. При DNS-ошибке откройте «Диагностика DNS». Приложение само DNS Windows не меняет.
7. В «Помощь» создайте ярлык. Крестик скрывает окно в трей; «Выход» завершает обход.

Обновления
В версии 0.3.0 автообновления оболочки включены. Приложение проверяет GitHub при
запуске и каждые 15 минут. Сборка скачивается с проверкой SHA-256, устанавливается
при выключенном обходе. При активном обходе можно нажать «Обновить оболочку»;
после перезапуска подключение восстановится. Настройки и списки сохраняются.
Обновления самого ядра Flowseal — отдельная кнопка в «Обновления».
Из 0.1/0.2 на 0.3.0 нужно перейти вручную один раз.

Что проверить и прислать автору
- Версия Windows, провайдер, Wi-Fi или кабель.
- Результат автоподбора: какой вариант выбран, какие сервисы недоступны.
- Результат проигрывания YouTube и голосового канала Discord.
- Работают ли «Применить и проверить», отмена подбора и выход из трея.
- Сбрасываются ли старые результаты после выключения/смены стратегии.
- Скриншот ошибки и строки из «Журнал». В data/app.log могут быть личные домены:
  просмотрите файл перед отправкой и удалите лишнее.

Выбор стратегии зависит от сети. Если ни один вариант не дал 5/5, посмотрите
таблицу и диагностику DNS; можно вручную применить вариант с нужными сервисами.

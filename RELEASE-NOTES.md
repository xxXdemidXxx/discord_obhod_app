# Обход 0.4.2

- Вкладка «Сайты» переименована в «Дополнительно» и перенесена перед «Помощь».
- Уточнено назначение правил: обработка отдельных сайтов может помочь против некоторых блокировок провайдера. Приложение не меняет IP или страну и не снимает региональные ограничения самого сервиса. Добавление домена не гарантирует доступ.

Для обновления откройте «Обновления» → «Проверить обновления». Настройки и списки сохраняются. Для первого запуска скачайте Obhod-0.4.2-win-x64.zip, распакуйте всю папку и откройте Obhod.exe.

# ByPass 0.5.0

## [⬇ Скачать ByPass для Windows](https://github.com/xxXdemidXxx/discord_obhod_app/releases/latest/download/ByPass-win-x64.zip)

Скачайте ZIP, нажмите правой кнопкой → «Извлечь всё», откройте `ByPass/ByPass.exe` и нажмите «Подобрать автоматически». Сохраняйте папку целиком. Нужны Windows 10/11 x64 и .NET Framework 4.8.

В этой версии:

- Обновления оболочки проверяются по независимой цифровой подписи. Подмена архива, EXE, config или локальных хешей отменяет установку.
- Перед запуском проверяются бинарные файлы, драйверы и стратегии ядра по подписанному каталогу. Включено проверенное ядро 1.10.3; новые версии требуют обновления каталога в оболочке.
- Повышенные права получает отдельный компонент запуска ядра. При обычном запуске окно работает с правами пользователя. Ядро запускается из защищённой папки.
- Сборка и готовый пакет проверяются в CI; релиз сначала создаётся как черновик, затем подписывается локальным ключом владельца и публикуется.
- Подготовлено подключение настоящего сертификата издателя Windows. Сертификата пока нет; предупреждения SmartScreen возможны.
- Сохранены подтверждения обновлений «Да / Нет» и пользовательские списки.

После обновления старой установки закройте программу через «Выход» и запустите обычным двойным щелчком. Если старое ядро не проходит проверку, распакуйте новый полный ZIP в новую папку и перенесите свои добавленные сайты через «Дополнительно».

Отчёт Microsoft Defender с временем, базами и хешами приложен к релизу. Чистая проверка не гарантирует отсутствия срабатываний других антивирусов. При обнаружении угрозы не отключайте защиту и не добавляйте исключения.

[Как устроена защита](https://github.com/xxXdemidXxx/discord_obhod_app/blob/main/SECURITY.md). Архив `Obhod-0.5.0-win-x64.zip` сохранён для обновляторов старых версий.

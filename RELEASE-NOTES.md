# Обход 0.4.1

- Исправлена двойная рамка и системный заголовок окна после разворачивания и переключения между окнами.
- Обновления приложения читаются из описания, опубликованного вместе со сборкой, без обращения к GitHub REST API. Проверка SHA-256 и версии EXE сохранена.
- Проверки сервисов больше не тратят лимит GitHub API при переборе стратегий.
- При временном ограничении обновлений ядра показывается понятный статус; повторные запросы ждут разрешённого GitHub времени. Всплывающего окна с ошибкой 403 нет.
- «Сайты»: понятное добавление адреса или ссылки, удаление записи крестиком, пояснение, что YouTube и Discord уже настроены. Служебные комментарии скрыты. Редактирование полным списком доступно отдельно.
- Пустые пользовательские списки сохраняются в совместимом с ядром виде.

Автоматическая проверка обновлений по-прежнему выполняется только при запуске.

**Обновление:** откройте «Обновления» и проверьте приложение. Если старая версия показывает 403, скачайте **Obhod-0.4.1-win-x64.zip** вручную, завершите приложение через меню значка у часов и замените в своей папке только **Obhod.exe** и **Obhod.exe.config**. Папку **data** не заменяйте: там настройки и ваши списки. Если EXE у вас называется `Obhod-0.4.0.exe`, скопируйте новые EXE и config под существующими именами, чтобы ярлык продолжал работать.

Для первого запуска распакуйте всю папку и откройте Obhod.exe. Windows 10/11 x64, .NET Framework 4.8.

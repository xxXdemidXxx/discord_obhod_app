# ByPass 0.5.7

- Исправлен подтверждённый журналом отказ запуска: Windows сохранила регистрацию WinDivert с путём к отсутствующему файлу из старой папки zapret 1.9.8c. В 0.5.6 восстановление касалось только собственных папок ByPass.
- Перед запуском проверенной оригинальной версии ядра удаляется только остановленная регистрация WinDivert с типом kernel driver, запуском по запросу и действительно отсутствующим WinDivert32.sys или WinDivert64.sys. Статус и путь проверяются повторно; при внешнем winws очистка не выполняется.
- ByPass не останавливает активный драйвер, не удаляет файлы старой папки и не меняет службы других имён. Оригинальная WinDivert.dll сама зарегистрирует драйвер из текущего ядра.
- Учтена отложенная очистка службы Windows: если её удерживает другой процесс, запуск останавливается с подсказкой о перезагрузке. Подробности восстановления попадают в журнал.
- Добавлены автономные проверки именно сценария со старой папкой 1.9.8c, активных служб, отказов доступа и изменения состояния во время восстановления. Настоящий драйвер и настоящие службы в тестах не изменяются. Файлы ядра 1.10.3, BAT и параметры запуска сохранены.

# ByPass 0.5.6

- Успешные сетевые пробы больше не объявляются подтверждением работы установленного Discord. Появились кнопки «Работает» для сохранения проверенного пользователем варианта и «Не работает» для продолжения подбора без повторения отклонённых вариантов.
- Сначала проверяется подтверждённая пользователем стратегия для текущей версии ядра, затем текущая сохранённая стратегия. Полный подбор также предпочитает этот вариант, если он проходит пробы.
- При отказе WinDivert подбор останавливается с отдельным сообщением и записью пути зарегистрированного драйвера в журнал. Повторное восстановление стратегии после общей ошибки запуска отменено.
- При выходе сохраняется файл драйвера, на который ещё ссылается служба Windows. При следующем запуске отсутствующий драйвер восстанавливается только по точному пути собственного runtime ByPass и только из проверенных файлов оригинального ядра. Чужие службы и их файлы не изменяются.
- Ядро 1.10.3, исходные BAT и параметры запуска не изменены. Регрессии проверяются автономно; доступность у провайдера и результат на другом компьютере требуют повторной проверки без VPN.

# ByPass 0.5.5

- Проверка Discord теперь включает приложение с выборочной загрузкой JS, реальный Gateway WebSocket с Hello и heartbeat ACK, а также отдельную проверку сервера обновлений Windows x64 и чтение начала файла из CDN.
- Успешный HTTP-ответ сайта или API больше не позволяет выбрать стратегию, если сервер обновлений или Gateway недоступен. Некорректный JSON, HTML вместо файла и обрыв загрузки не дают зелёный результат. Тайм-аут действует и после получения заголовков.
- Проверки начинаются после сообщения оригинального ядра о готовности перехвата. Файлы ядра, BAT-стратегии и параметры запуска сохраняются без изменений.
- Журнал сохраняет результаты каждого сервиса для каждой проверенной стратегии и её повторного подтверждения.
- Добавлены автономные тесты сбоев без VPN и без запуска настоящего драйвера. Работа у конкретного провайдера требует проверки без VPN; сетевые пробы не подтверждают запуск установленного клиента, голос и полную загрузку обновления.

# ByPass 0.5.4

## [⬇ Скачать ByPass для Windows](https://github.com/xxXdemidXxx/discord_obhod_app/releases/latest/download/ByPass-win-x64.zip)

Распакуйте ZIP целиком, откройте `ByPass/ByPass.exe` и нажмите «Подобрать автоматически». Нужны Windows 10/11 x64 и .NET Framework 4.8.

- Исправлен отказ доступа к `WinDivert64.sys` при переключении стратегий: проверенные файлы ядра используются повторно, даже когда Windows удерживает драйвер.
- При общей ошибке запуска автоподбор останавливается, вместо одинаковых ошибок во всех строках.
- Системные исключения больше не появляются в автоматических пугающих окнах: приложение показывает спокойную подсказку с дальнейшим действием. Подробности сохраняются в «Журнале».
- Во вкладке «Журнал» появилась кнопка «Сохранить лог». Один TXT-файл можно прислать разработчику; он содержит версии, состояние и сообщения приложения.
- Окно можно растягивать за края и углы. Исправлен расчёт разворачивания для разных мониторов и положения панели задач.
- Нижняя область со ссылкой удалена. Отметка подписи автора находится обычной строкой в «Помощи».
- Во вкладке «Обновления» раздел ядра раскрыт сразу. Добавлены отдельные переключатели автоматической установки оболочки и ядра. По умолчанию они выключены; после включения обновления скачиваются, проверяются и устанавливаются без отдельного подтверждения при запуске.
- Если автообновление выключено, ручная установка по-прежнему требует ответа «Да / Нет». Пользовательские списки сохраняются, подписи и целостность проверяются в обоих режимах.
- Проверка сервисов теперь явно показывает, когда обход выключен.

Если установлена старая версия с ошибкой доступа, обновите оболочку, полностью закройте ByPass через значок у часов → «Выход» и откройте снова. Затем повторите автоподбор. Доступность видео и голоса отдельно проверьте в своей сети.

Выпуск подписан ключом автора. Отчёт Microsoft Defender приложен к релизу. Сертификата проверенного издателя Windows пока нет, предупреждения SmartScreen возможны. Архив `Obhod-0.5.4-win-x64.zip` сохранён для обновляторов старых версий.

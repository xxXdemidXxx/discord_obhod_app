# Обход 0.4.3

Обновления приложения теперь устанавливаются в одном окне:

- «Проверить обновления» → «Обновить» → автоматический перезапуск.
- При запуске выполняется только проверка. Скачивание начинается по кнопке.
- Прогресс, отмена загрузки и повторная попытка отображаются во вкладке, без всплывающих окон.
- Настройки и списки сохраняются. Включённое подключение восстанавливается после перезапуска.
- Установщик проверяет готовность до закрытия приложения. При сбое замены возвращается предыдущая сборка.
- Дополнительные действия с ядром скрыты в раскрываемом разделе «Компоненты обхода».

Для первого запуска скачайте Obhod-0.4.3-win-x64.zip, распакуйте всю папку и откройте Obhod.exe. Для обновления уже установленной версии используйте её вкладку «Обновления».

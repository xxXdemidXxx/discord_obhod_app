# Обход 0.4.0

- Новый интерфейс в стиле Discord: вкладки наверху, ровные блоки, тёмные списки и тонкие полосы прокрутки.
- Окно можно растягивать за края и разворачивать. Интерфейс адаптируется к размеру и масштабу Windows.
- Быстрый подбор останавливается на первом варианте, который прошёл повторную проверку. Полный перебор остаётся доступен.
- Сокращены паузы при смене стратегий. Проверки сервисов выполняются параллельно; подтверждение результата использует обычный тайм-аут.
- Страница «Сайты»: встроенное редактирование доменов и исключений, проверка ввода, сохранение и применение без работы с файлами вручную.
- Понятное объяснение игровых соединений; дополнительные настройки портов скрыты.
- Автоматические проверки обновлений выполняются только при запуске. Кнопка ручной проверки сохранена.
- Убраны нижняя подпись и лишние технические пояснения.

**Для обновления из 0.3.0:** откройте «Обновления» → «Проверить оболочку», затем установите доступную 0.4.0. При выключенном обходе проверенная сборка устанавливается автоматически. Настройки и пользовательские списки сохраняются.

Для первого запуска скачайте **Obhod-0.4.0-win-x64.zip**, распакуйте всю папку и откройте **Obhod.exe**. Нужны Windows 10/11 x64 и .NET Framework 4.8.

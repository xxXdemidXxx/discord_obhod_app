# ByPass 0.4.4

## [⬇ Скачать ByPass для Windows](https://github.com/xxXdemidXxx/discord_obhod_app/releases/latest/download/ByPass-win-x64.zip)

1. Скачайте ZIP и нажмите на него правой кнопкой → «Извлечь всё».
2. Откройте папку `ByPass` и запустите `ByPass.exe`.
3. Нажмите «Подобрать автоматически» и разрешите запуск в вопросе Windows.

Сохраняйте папку целиком. Нужны Windows 10/11, 64 бит, и .NET Framework 4.8.

В этой версии:

- Приложение переименовано в **ByPass**: окно, значок в трее, новый ярлык и архив для скачивания.
- Постоянная кнопка скачивает готовую программу. Git, сборка и исходники пользователю не нужны.
- README начинается с установки и объяснения работы. Подробная помощь и документация разработчика находятся отдельно.
- В окне видны ненавязчивые уведомления об обновлении оболочки и ядра. Установка начинается только после кнопки «Обновить» и подтверждения «Да»; можно выбрать «Нет».
- Сохранено обновление старых установок «Обход». Настройки и пользовательские списки сохраняются.

Если программа уже установлена, обновите её во вкладке «Обновления».

Архив с прежним именем `Obhod-0.4.4-win-x64.zip` предназначен для совместимости с обновляторами старых версий. Для новой установки используйте кнопку выше.

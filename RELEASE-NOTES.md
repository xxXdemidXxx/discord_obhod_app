# ByPass 0.5.4

## [⬇ Скачать ByPass для Windows](https://github.com/xxXdemidXxx/discord_obhod_app/releases/latest/download/ByPass-win-x64.zip)

Распакуйте ZIP целиком, откройте `ByPass/ByPass.exe` и нажмите «Подобрать автоматически». Нужны Windows 10/11 x64 и .NET Framework 4.8.

- Исправлен отказ доступа к `WinDivert64.sys` при переключении стратегий: проверенные файлы ядра используются повторно, даже когда Windows удерживает драйвер.
- При общей ошибке запуска автоподбор останавливается, вместо одинаковых ошибок во всех строках.
- Системные исключения больше не появляются в автоматических пугающих окнах: приложение показывает спокойную подсказку с дальнейшим действием. Подробности сохраняются в «Журнале».
- Во вкладке «Журнал» появилась кнопка «Сохранить лог». Один TXT-файл можно прислать разработчику; он содержит версии, состояние и сообщения приложения.
- Окно можно растягивать за края и углы. Исправлен расчёт разворачивания для разных мониторов и положения панели задач.
- Нижняя область со ссылкой удалена. Отметка подписи автора находится обычной строкой в «Помощи».
- Во вкладке «Обновления» раздел ядра раскрыт сразу. Добавлены отдельные переключатели автоматической установки оболочки и ядра. По умолчанию они выключены; после включения обновления скачиваются, проверяются и устанавливаются без отдельного подтверждения при запуске.
- Если автообновление выключено, ручная установка по-прежнему требует ответа «Да / Нет». Пользовательские списки сохраняются, подписи и целостность проверяются в обоих режимах.
- Проверка сервисов теперь явно показывает, когда обход выключен.

Если установлена старая версия с ошибкой доступа, обновите оболочку, полностью закройте ByPass через значок у часов → «Выход» и откройте снова. Затем повторите автоподбор. Доступность видео и голоса отдельно проверьте в своей сети.

Выпуск подписан ключом автора. Отчёт Microsoft Defender приложен к релизу. Сертификата проверенного издателя Windows пока нет, предупреждения SmartScreen возможны. Архив `Obhod-0.5.4-win-x64.zip` сохранён для обновляторов старых версий.

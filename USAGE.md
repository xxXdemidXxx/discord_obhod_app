# Помощь по ByPass

[Скачать программу](https://github.com/xxXdemidXxx/discord_obhod_app/releases/latest/download/ByPass-win-x64.zip) · [Установка и первый запуск](README.md)

## Как включить

Откройте `ByPass.exe` из распакованной папки. Нажмите **«Подобрать автоматически»** и разрешите запуск в вопросе Windows. Дождитесь результата, затем откройте нужный сайт.

Вместе с программой должны лежать папка `data`, файл `ByPass.exe.config` и остальные файлы из архива. Сохраняйте всю папку `ByPass`, а не один EXE.

Если у вас уже запущен другой zapret, остановите его в той программе, из которой он запускался.

## Что такое подбор

Программа пробует несколько способов подключения — они называются стратегиями. Вручную разбираться в их названиях не обязательно.

- **Быстрый** режим включён по умолчанию. Он останавливается на первом варианте, который дважды прошёл проверку.
- **Полный** режим проверяет все варианты и повторно проверяет лучшие. Выберите его, если быстрый подбор не помог.
- **Отмена** прекращает поиск и возвращает прежнее подключение, если оно было включено.
- **Остановить подбор** прекращает поиск и выключает обход.

Можно выбрать вариант из списка и нажать **«Применить и проверить»**. Программа сама переключит подключение.

Проверки относятся к YouTube, Discord и GitHub. Для Discord отдельно проверяются HTML приложения с выборочной загрузкой JavaScript, API с подключением к Gateway и ответом на heartbeat, а также манифест обновлений Windows x64 с чтением первых 1024 байт файла из CDN. Строка «Discord · обновления» помогает обнаружить зависание на маленьком окне проверки обновлений. Это сетевые пробы без входа в аккаунт: они не подтверждают запуск установленного клиента, полную загрузку обновления, воспроизведение видео или голосовой канал. Откройте клиент, ролик и голосовой канал отдельно.

При включённом VPN результаты относятся к подключению через VPN. Для проверки обхода у вашего провайдера выключите VPN и повторите подбор. Оригинальное ядро и параметры BAT-стратегий оболочка не изменяет.

Кнопка «Проверить сервисы» сама не включает обход. Если рядом с результатом написано «обход выключен», проверяется обычное подключение к интернету. Нажмите «Подобрать автоматически», чтобы попробовать включить обход.

Если не удалось запустить ядро, подбор остановится и в окне появится понятная подсказка. По кнопке «Журнал» можно открыть подробности для разработчика. Сообщение можно скрыть крестиком и повторить действие. Технические пути и системные исключения не появляются в автоматических всплывающих окнах.

## Если написано DNS

Это означает, что компьютер не смог определить адрес сайта по его имени. Нажмите **«Диагностика DNS»** и прочитайте результат.

Программа сама не меняет DNS в настройках Windows. При необходимости во встроенной диагностике есть кнопка с инструкцией по настройке.

## Как выключить и закрыть

**«Выключить»** останавливает обход, окно остаётся открытым.

**Крестик** скрывает окно. Программа продолжает работать. Для возвращения окна дважды нажмите на значок ByPass рядом с часами.

Для полного завершения нажмите правой кнопкой на этот значок → **«Выход»**. Если значка не видно, нажмите стрелку `^` рядом с часами. При выключенном автозапуске программа остановит своё подключение. Если включён запуск при старте Windows, служба продолжит работать; остановить её можно кнопкой «Выключить».

Чтобы изменить размер окна, потяните за край или угол. Кнопка **«□»** сверху разворачивает окно в пределах экрана, повторное нажатие возвращает прежний размер. Отметка подписи автора находится во вкладке **«Помощь»** и никуда не перенаправляет.

## Как обновить

При запуске программа проверяет наличие новых версий, если включено «Проверять при запуске». По умолчанию автоматическая установка выключена.

Чтобы новые версии устанавливались сами, откройте **«Обновления»** и включите **«Скачивать и устанавливать автоматически»**. У оболочки и ядра свои переключатели; можно включить любой из них или оба. Тогда при запуске обнаруженное обновление скачивается, проверяется и устанавливается без вопроса «Да / Нет». Оболочка перезапускается, а при обновлении ядра своё подключение временно останавливается и восстанавливается. Включённое автообновление также включает проверку при запуске. Выключить его можно тем же переключателем.

Если другая программа обхода уже работает или ваши изменения в «Дополнительно» ещё не сохранены, автоматическая установка ядра откладывается. Новые ядра загружаются прямо из официальных стабильных релизов Flowseal; отдельного обновления оболочки для каждой версии ядра не требуется.

Если обновление найдено, в окне появляется надпись:

- **«Доступна новая версия оболочки»** — обновление самого ByPass.
- **«Доступна новая версия ядра»** — обновление компонентов, которые выполняют обход.

Для ручной установки нажмите рядом **«Обновить»**. В вопросе о подтверждении выберите **«Да»**, чтобы начать, или **«Нет»**, чтобы оставить текущую версию. Крестиком рядом с уведомлением можно скрыть его до следующего запуска. Проверить обновления вручную можно во вкладке **«Обновления»**.

При обновлении ядра скачивание и проверка проходят при работающем обходе. Для переключения ByPass ненадолго останавливает своё подключение и восстанавливает его автоматически. Если новое ядро не запускается, программа возвращает прежнее ядро и пробует восстановить подключение. Предыдущее ядро также можно вернуть во вкладке «Обновления», в разделе «Ядро».

При обновлении оболочки программа перезапустится. Если обход был включён, она восстановит подключение. Настройки и добавленные сайты сохранятся.

Если загрузка не удалась, повторите попытку позже. Установленная версия останется на месте.

Если написано, что подпись оболочки или файлы ядра не прошли проверку, повторите обновление при доступном GitHub. Для первого запуска нового ядра нужна сеть, чтобы подтвердить его официальный релиз; после успешного запуска проверка работает и без сети. Если ошибка повторяется, сохраните журнал через кнопку «Сохранить лог».

Запрос Windows относится к отдельному компоненту запуска ядра. При обычном запуске окно ByPass работает без прав администратора. Для первого включения разрешите запрос; если выбрать «Нет», обход не запустится. В пределах этого запуска помощник используется повторно. После перехода со старой версии закройте ByPass через «Выход» и откройте обычным двойным щелчком.

Если антивирус сообщает об угрозе, не отключайте его и не добавляйте папку в исключения. Сохраните название обнаружения и сообщите о нём через ссылку внизу. [Описание защиты](SECURITY.md).

В старых версиях «Обход» обновление через программу сохранено. После обновления окно будет называться ByPass; прежнее имя EXE в вашей папке может остаться. Для новой установки скачивайте архив по кнопке в README.

## Дополнительные настройки

Для YouTube и Discord всё уже настроено. Игровые соединения и списки сайтов во вкладке **«Дополнительно»** можно оставить как есть.

Если нужно добавить другой сайт: **«Дополнительно» → вставьте ссылку → «Добавить» → «Сохранить»**. Если обход включён, используйте **«Сохранить и применить»**. Удалить сайт можно крестиком рядом с его адресом.

Добавление сайта не гарантирует доступ. Программа не меняет IP-адрес и страну, поэтому ограничения самого сайта по стране могут остаться.

«Игровые соединения» оставьте выключенными, если вы не настраиваете обход для конкретной игры.

## Если нужна помощь

[Создайте обращение](https://github.com/xxXdemidXxx/discord_obhod_app/issues) и укажите:

- вашу версию Windows и провайдера;
- что именно не работает;
- результат подбора и выбранный вариант;
- работают ли видео YouTube и голос Discord.

Откройте **«Журнал» → «Сохранить лог»**, выберите папку и сохраните TXT-файл. В нём будут версии, состояние подключения и сообщения приложения; полный путь к вашей папке пользователя скрывается. Приложите файл и при необходимости снимок окна. Перед отправкой проверьте, нет ли в журнале личных адресов сайтов.

## Автозапуск

В «Настройки» включите «Запускать при старте Windows». Подтвердите запрос Windows один раз для настройки службы. Обход включится при загрузке системы; после входа в учётную запись ByPass появится только в трее. Двойной щелчок открывает окно.

Пока галочка включена, «Выход» закрывает программу, а обход продолжает работать службой. «Выключить» останавливает обход до следующего старта Windows. Снятие галочки удаляет службу и запуск значка; при работающем обходе он продолжит работать до выхода из приложения. Перед переносом папки программы отключите автозапуск, затем включите его в новой папке.
## Отдельное окно YouTube при ошибке DNS

Если Windows не находит YouTube, откройте «Диагностика DNS» и нажмите «Открыть YouTube в отдельном окне». Установленный Edge/Chrome запустится с отдельным профилем и DNS через HTTPS для этого окна. Основной профиль, DNS Windows и остальные программы сохраняют прежние настройки. Системный прокси и сертификаты не меняются.

Оставьте ByPass и выбранную стратегию включёнными. Проверьте воспроизведение видео. После выхода или обновления ByPass откройте отдельное окно заново кнопкой. При ошибке DNS Windows проверки YouTube повторяются через DoH. Статус «Доступен через DoH» подтверждает HTTPS-ответ по этому маршруту; подробности сохраняют исходную DNS-ошибку. Этот режим проверяет обход проблемы DNS, а доступность видео зависит также от сети и стратегии.
## Оформление и короткие инструкции

В **«Настройки»** выберите тему **«Графит»**, **«Полночь»** или **«Обсидиан»**. Она применяется сразу и сохраняется после перезапуска. Там же находятся переключатель автозапуска и создание ярлыка.

Для игровых настроек откройте **«Дополнительно» → «Игровые соединения»**. Рядом доступны **«Правила для сайтов»**. При включённом обходе игровые настройки заблокированы: сначала выключите обход.

В **«Помощь»** находятся короткие инструкции начала работы, настройки DNS в Chrome/Edge и DNS Windows. Кнопки **«Помощь: DNS в браузере»** и **«Помощь: DNS в Windows»** в диагностике закрывают её и открывают выбранную инструкцию. DNS Windows меняется вручную; сохраните прежние настройки перед изменением.

При ошибке системного DNS ByPass автоматически повторяет проверки сайта и изображений YouTube через DNS по HTTPS (DoH). Успешный HTTPS-ответ показывается как «Доступен через DoH». Это не меняет DNS Windows и настройки браузера и не проверяет воспроизведение видео.

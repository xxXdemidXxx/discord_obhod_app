# ByPass

## [⬇ Скачать ByPass для Windows](https://github.com/xxXdemidXxx/discord_obhod_app/releases/latest/download/ByPass-win-x64.zip)

### Установка и первый запуск

1. Нажмите **«Скачать ByPass для Windows»** выше. Скачается файл `ByPass-win-x64.zip`.
2. Найдите его в папке **«Загрузки»**. Нажмите на файл правой кнопкой мыши → **«Извлечь всё»** → **«Извлечь»**.
3. Откройте распакованную папку **`ByPass`** и запустите **`ByPass.exe`**.
4. В окне программы нажмите **«Подобрать автоматически»**. Если Windows спросит разрешение на внесение изменений, нажмите **«Да»**.
5. Дождитесь сетевых проб. Откройте YouTube или Discord. Если всё работает, нажмите «Работает»; иначе «Не работает» — подбор продолжится со следующим вариантом.

**Папку `ByPass` сохраняйте целиком.** Файл `ByPass.exe` и папка `data` должны лежать рядом. Программу можно перенести в удобное место, например `C:\ByPass`.

Подходит для **Windows 10/11, 64 бит**. Нужен **.NET Framework 4.8**. Git, команды и сборка программы для запуска не нужны.

### Как это работает

ByPass помогает восстановить доступ к YouTube и Discord через ваше обычное подключение к интернету. Программа использует Flowseal zapret и меняет способ передачи некоторых сетевых пакетов, чтобы обойти поддерживаемые фильтры провайдера.

Кнопка **«Подобрать автоматически»** сначала проверяет сохранённый вариант, затем остальные. Успешные сетевые пробы предлагают вариант для проверки в Discord. Кнопка **«Работает»** сохраняет подтверждённую вами стратегию с приоритетом для следующего подбора; **«Не работает»** продолжает подбор, пропуская отклонённые варианты до нового явного сканирования. Результат зависит от провайдера и способа блокировки. IP-адрес и страна подключения не меняются.

### Что нажимать дальше

- **Выключить обход:** кнопка **«Выключить»** в программе.
- **Закрыть окно:** крестик справа сверху. Программа продолжит работать; её значок останется рядом с часами Windows.
- **Запускать при старте Windows:** в «Настройки» включите одноимённую галочку и подтвердите запрос Windows. Обход запускается службой до входа в систему, а окно после входа остаётся в трее. Двойной щелчок по значку открывает его. При включённой галочке «Выход» оставляет обход работающим; кнопка «Выключить» останавливает его до следующего старта Windows. Чтобы убрать автозапуск, снимите галочку.
- **Завершить программу:** нажмите правой кнопкой на значок рядом с часами → **«Выход»**. Если значка не видно, откройте стрелку **`^`** рядом с часами.
- **Изменить размер окна:** потяните за край или угол. Кнопка **«□»** сверху разворачивает окно; повторное нажатие возвращает прежний размер.
- **Обновить вручную:** при появлении надписи **«Доступна новая версия оболочки»** или **«Доступна новая версия ядра»** нажмите рядом **«Обновить»**. В вопросе о подтверждении выберите **«Да»** или **«Нет»**.
- **Обновлять автоматически:** во вкладке **«Обновления»** включите **«Скачивать и устанавливать автоматически»** для оболочки, ядра или обоих. При запуске новые версии будут скачиваться и устанавливаться без отдельного вопроса. По умолчанию оба переключателя выключены.

### Если не заработало

Попробуйте выбрать **«Полный»** режим и снова нажать **«Подобрать автоматически»**. Если написано **«DNS»**, нажмите **«Диагностика DNS»**. Если запущена другая программа zapret, сначала выключите её.

Проверки Discord отдельно проверяют веб-приложение, Gateway и сервер обновлений с чтением начала файла из CDN. Успешный результат означает прохождение этих сетевых проб; запуск установленного клиента ими не подтверждается. **Видео YouTube и голосовой канал Discord проверьте сами.** Настройки игр и вкладку «Дополнительно» для обычного запуска менять не требуется.

Если после старого zapret осталась остановленная служба WinDivert с отсутствующим файлом, ByPass удалит устаревшую регистрацию перед запуском. Оригинальная DLL зарегистрирует драйвер текущего ядра. Активные драйверы и работающий внешний winws эта очистка не затрагивает. Если Windows удерживает удаляемую службу, потребуется перезагрузка.

Если обход не удалось включить, в окне появится сообщение с подсказкой. Подробности доступны по кнопке **«Журнал»**. Когда обход выключен, **«Проверить сервисы»** проверяет ваше обычное подключение; доступ только к GitHub ещё не означает, что обход работает.

Чтобы прислать подробности разработчику: **«Журнал» → «Сохранить лог»**. Сохраните TXT-файл и приложите его к сообщению.

### Проверка безопасности

Программа проверяет подпись обновлений и целостность ядра перед запуском. Если файлы изменены, запуск отменяется. Готовый выпуск проверяется Microsoft Defender; отчёт находится на странице версии. Сертификата проверенного издателя Windows пока нет, поэтому SmartScreen может показать предупреждение. Если антивирус пишет об угрозе, не отключайте защиту: сообщите название обнаружения через ссылку ниже. [Подробнее о защите](SECURITY.md).
